# Syed Shayan - Insights Page (PHP Implementation)

This project is a pixel-perfect, responsive replica of the **Syed Shayan Insights** page ([syedshayan.com/insights](https://syedshayan.com/insights)), developed in pure **PHP 8+** with semantic HTML5, Tailwind CSS, and custom responsive typography.

---

## 🚀 How to Run Locally

### Prerequisites
- PHP 8.0 or higher installed.

### Option A: Using PHP Built-in Server (Quickest)
1. Open your terminal / command prompt in this project folder.
2. Run the following command:
   ```bash
   php -S 127.0.0.1:8000
   ```
3. Open your browser and navigate to:
   ```
   http://127.0.0.1:8000/
   ```

### Option B: Using XAMPP / WampServer / Laragon
1. Copy or move this project folder into your server's web root:
   - **XAMPP:** `C:\xampp\htdocs\shayan`
   - **WampServer:** `C:\wamp64\www\shayan`
   - **Laragon:** `C:\laragon\www\shayan`
2. Start the Apache service.
3. Visit `http://localhost/shayan/` in your browser.

## ✨ Key Features
- **Pure PHP Engine:** Runs natively on any standard PHP 8+ web server without requiring Node/npm build steps.
- **Dynamic Headers & Metadata:** Clean PHP variables controlling page title, SEO tags, and copyright year.
- **100% Asset Integrity:** All badges, Urdu calligraphy, hero graphics, and icons load locally with zero broken assets.
- **Fully Responsive:** Customized media queries supporting Mobile, Tablet, Laptop, and 4K displays.
